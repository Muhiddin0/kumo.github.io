## Botspace

Platforma uchun bot konstruktori, admin panel va landing sahifani ishlab chiqdim. Django backend API’lari va til modellari integratsiyasi ustida ham ishladim. Platformada 2 000 ga yaqin foydalanuvchi ro‘yxatdan o‘tgan.
